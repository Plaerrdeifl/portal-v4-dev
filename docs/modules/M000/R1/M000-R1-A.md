# M000-R1-A — Core and contracts

## Implemented files and responsibilities

- `scripts/operator/portal-operator.ps1`: PowerShell 5.1 entry point, invocation classification, safe package-A completion, and process exit code.
- `scripts/operator/modules/Operator.Core.psm1`: version/stage constants, timeout profiles, run IDs and run directories, and the code-owned check-registry foundation.
- `scripts/operator/modules/Operator.Manifest.psm1`: byte hashing, strict UTF-8 and JSON parsing, duplicate-property detection, schema-keyword enforcement, recursive schema validation, and manifest snapshots.
- `scripts/operator/modules/Operator.Reporting.psm1`: UTF-8 atomic writes, result construction and validation, base reports, and guarded central success-marker mapping.
- `scripts/operator/schemas/manifest-v1.schema.json`: closed manifest schema 1.
- `scripts/operator/schemas/result-v1.schema.json`: closed result schema 1.
- `docs/project/operator-framework-contracts-v1.md`: version-1 framework contracts.
- `docs/modules/M000/R1/M000-R1-A.md`: package-A implementation record.

## Security boundaries

Manifest content is data only and is never evaluated. JSON must be valid UTF-8, strict, free of duplicate properties, at most 1,048,576 bytes for manifests, and no deeper than 32 recursive levels. Schema keywords outside the explicitly supported subset cause an internal error. Reports never copy rejected manifest content; they contain only a rejection object and, when readable, the original-byte SHA-256. Atomic writes use temporary files in the target directory and clean them in `finally`.

## Deliberately not implemented

This package has no repository/Git checks, path policies, fingerprints, tool or secret checks, process execution or management, health checks, external-process timeouts, process cleanup, Pester suite, complete SelfTest, LocalVerify, LocalFreeze, deployment logic, or domain modules. It registers and executes no checks. `scripts/operator/manifests/M000-R1.json` will be created only by a later approved package.

M000-R1-A never creates a `passed` operator result and never emits a success marker. This package does not claim that M000-R1 is complete.

## Local validation

Validation parses every PS1/PSM1 with `System.Management.Automation.Language.Parser`, strictly parses both schemas, exercises accepted and rejected temporary manifests and results, and invokes `SelfTest`, `DevDeploy`, invalid-manifest, and missing-manifest reference cases. Temporary fixtures live under a unique `%TEMP%` directory and are removed in `finally`. Repository boundaries are checked with Git status, diff-name, whitespace, and stat commands.
