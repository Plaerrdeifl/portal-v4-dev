# Dashboard Layout Corr3

## Ziel

Beseitigung der seitlichen Dashboard-Textspalte und aller willkürlichen
Wortumbrüche.

## Release

`20260724-dashboard-layout-corr3`

## Layoutregeln

- Kartenkopf immer oberhalb des Inhalts;
- Karteninhalt immer über die vollständige Breite;
- normales Umbrechen ausschließlich an Wortgrenzen;
- unter 1000 px alle Karten vollbreit;
- Vorstandsaufgaben auf Desktop vollbreit;
- Kennzahlenkarten in ausgeglichenen 4/8-Rastern.

## Abgrenzung

Keine Änderung an Backend, Datenbank, Rollen oder Dashboard-Fachdaten.
